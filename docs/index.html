How it works

One gesture.
No app to open.

01 Drag and tap Shift

Start dragging a file from Files or your desktop, then tap Shift. Orbit's card opens right under your pointer.

02 Pick a tile

The tile under your pointer gets an outline, and a short line says what it does. Tap Shift again for Tools.

03 Drop. That's it.

Progress shows while it works. When it's done you hear a short chime and the new file is next to the original.

Privacy

Your files never
leave your computer.

No internet

Orbit makes no network connections. No accounts, no uploads, no tracking.

Originals untouched

Every result is a new file next to the original. Nothing is ever overwritten.

Open source

MIT licensed. The gesture code is about 100 lines and easy to read.

Install

Three lines.
One log in.

For Ubuntu 24.04 and newer. The installer sets everything up, then log out and back in once.

# get Orbit
$ git clone https://github.com/jsticks779/orbit.git
$ cd orbit
$ ./setup.sh

Try it on
your next file.
